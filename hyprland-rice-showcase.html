Setup Guide
STEP 1 Install Everything
Run these in order. The rice requires Hyprland 0.55+ for Lua config support — AUR has it. 
# Pacman (official repos)
sudo pacman -Syu
sudo pacman -S --needed waybar kitty neovim rofi-wayland swaync yazi   fastfetch btop starship cliphist wl-clipboard swappy grim slurp hyprpicker lesspipe   noto-fonts noto-fonts-emoji ttf-jetbrains-mono-nerd ttf-nerd-fonts-symbols-mono   papirus-icon-theme polkit-gnome   xdg-desktop-portal-hyprland xdg-desktop-portal-gtk   uwsm pipewire wireplumber pipewire-pulse pipewire-alsa pavucontrol gtk3   networkmanager nm-connection-editor network-manager-applet   zsh hyprland hyprlock hypridle hyprpaper qt5-wayland qt6-wayland   playerctl bluez bluez-utils blueman mpv imv zathura zathura-pdf-mupdf   fd ripgrep bat tealdeer easyeffects brightnessctl p7zip unrar xdg-utils yt-dlp python-mutagen   noto-fonts-cjk ttf-liberation

# Yay / AUR (Hyprland 0.55+ Lua API required)
yay -S swayosd-git grimblast-git ttf-share-tech-mono bibata-cursor-theme   vivaldi vivaldi-ffmpeg-codecs timeshift
STEP 2 Enable Systemd Services
Replace old exec-once with proper user services for crash resilience & journalctl logs. 
# Copy service files
mkdir -p ~/.config/systemd/user
cp ~/hyprarch/configs/systemd/user/*.service ~/.config/systemd/user/

# Enable all four daemons
systemctl --user enable --now hyprpaper hypridle swaync cliphist

# Check logs if something isn't working
journalctl --user -u hyprpaper -f

# Bluetooth stack (system-wide)
sudo systemctl enable --now bluetooth

# Timeshift scheduler (cronie)
sudo systemctl enable --now cronie
⚠️ Remove the corresponding hl.exec_cmd() lines from hyprland.lua if using these services. The included config already has them commented.
STEP 3 Apply Configs
Clone the dotfiles and symlink everything into place. 
cd ~
git clone https://github.com/Nine129/hyprarch
cd hyprarch

# Symlink configs (overwrites existing)
for dir in configs/*/; do
  name=$(basename "$dir")
  ln -sfT "$(pwd)/configs/$name" "$HOME/.config/$name"
done

# Manually link files at config root level
ln -sf configs/shell/.zshrc ~/.zshrc
ln -sf configs/shell/.zshenv ~/.zshenv
ln -sf configs/starship.toml ~/.config/starship.toml
ln -sf configs/fontconfig/fonts.conf ~/.config/fontconfig/fonts.conf

# Make scripts executable
chmod +x ~/.config/hypr/scripts/*.sh
STEP 4 Set Up Zsh
Change shell, install plugins, and configure Starship with the CGGX prompt. 
# Zsh as default shell (logout & re-login after)
chsh -s /usr/bin/zsh

# Starship prompt (CGGX config included in dotfiles)
cp ~/hyprarch/configs/starship.toml ~/.config/starship.toml

# Zsh plugins (optional but recommended)
mkdir -p ~/.zsh/plugins
git clone https://github.com/zsh-users/zsh-autosuggestions   ~/.zsh/plugins/zsh-autosuggestions
git clone https://github.com/zsh-users/zsh-syntax-highlighting   ~/.zsh/plugins/zsh-syntax-highlighting
STEP 5 Reboot & Launch
Log out of your current session and select Hyprland from the display manager, or start via uwsm. 
# Update tealdeer (tldr) cache
tldr --update

# Reboot after steps 1-4
sudo reboot

# On next login: select "Hyprland (uwsm)" from SDDM / greetd
# Or from a TTY:
export XDG_SESSION_TYPE=wayland
exec uwsm start hyprland
STEP 6 Verify
Quick checklist to confirm everything is running. 
# 1. Hyprland version (must be 0.55+)
hyprctl version | head -1

# 2. Waybar running
pgrep waybar && echo "waybar OK"

# 3. Services active
systemctl --user is-active hyprpaper hypridle swaync

# 4. Clipboard manager
echo "test" | wl-copy && cliphist list | head -1

# 5. Screenshot with grimblast
grimblast copy output

# 6. Bluetooth running
bluetoothctl show | grep -q "Powered" && echo "bluetooth OK"

# 7. Keybind: SUPER+Q opens kitty
# 8. Keybind: SUPER+E opens yazi
# 9. Keybind: Print copies screenshot to clipboard
STEP 7 Configure Timeshift Backups
Automatic BTRFS/RSYNC snapshots with cronie scheduler. Protects against bad updates or config mistakes. 
# 1. Open Timeshift GUI:
pkexec timeshift-gtk

# 2. Select snapshot type:
#    - BTRFS  if root is BTRFS
#    - RSYNC  if ext4 (default for most Arch installs)

# 3. Choose snapshot location (usually root device)

# 4. Set schedule (recommended):
#    Daily:   5 snapshots, keep last 3
#    Weekly:  3 snapshots, keep last 2
#    Monthly: 2 snapshots, keep last 1

# 5. Click "Create" for first manual snapshot, then
#    cronie handles automatic snapshots.

# Manual snapshot:
sudo timeshift --create --comments "before-update"

# List snapshots:
sudo timeshift --list

# Restore:
sudo timeshift --restore

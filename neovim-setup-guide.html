1 Directory structure

Everything lives under ~/.config/nvim/. We'll organize it cleanly with a personal namespace (cggx) and separate plugin specs under lazy/.

~/.config/nvim/ ├── init.lua « entry point └── lua/ └── cggx/ ├── init.lua « requires everything ├── lazy_init.lua « bootstraps lazy.nvim ├── settings.lua « basic vim options ├── theme.lua « colorscheme + highlights ├── keymaps.lua « leader key + mappings └── lazy/ ├── treesitter.lua ├── telescope.lua ├── nvimtree.lua ├── bufferline.lua ├── lsp.lua └── lualine.lua

Create the directories:

mkdir -p ~/.config/nvim/lua/cggx/lazy

2 Install lazy.nvim

Lazy is the modern plugin manager used by 4 of the 5 blogs we researched. It auto-installs itself, lazy-loads plugins, and has a built-in UI (:Lazy).

Create ~/.config/nvim/lua/cggx/lazy_init.lua

This file bootstraps lazy: it clones the repo if missing, adds it to the runtime path, and tells lazy to look for plugin specs in the cggx.lazy module (i.e. lua/cggx/lazy/*.lua).

-- ~/.config/nvim/lua/cggx/lazy_init.lua
local lazypath = vim.fn.stdpath("data") .. "/lazy/lazy.nvim"
if not (vim.uv or vim.loop).fs_stat(lazypath) then
  vim.fn.system({
    "git",
    "clone",
    "--filter=blob:none",
    "https://github.com/folke/lazy.nvim.git",
    "--branch=stable",
    lazypath,
  })
end
vim.opt.rtp:prepend(lazypath)

-- Plugin specs live in lua/cggx/lazy/*.lua
require("lazy").setup({
  spec = "cggx.lazy",
  change_detection = { notify = false },
})

3 Base editor settings

These are the foundation — line numbers, tabs, search behavior, clipboard, yank highlight. Inspirations drawn from vale.rocks (smart line numbers, scrolloff, persistent undo) and poltora.dev (tabs, mouse, encoding).

Create ~/.config/nvim/lua/cggx/settings.lua

-- ~/.config/nvim/lua/cggx/settings.lua
local o = vim.o
local a = vim.api

── Line numbers ──────────────────────
o.number = true
o.relativenumber = true

── Tabs & indentation ────────────────
o.tabstop = 2
o.shiftwidth = 2
o.softtabstop = 2
o.expandtab = true
o.autoindent = true
o.smartindent = true

── Visual ─────────────────────────────
o.cursorline = true
o.scrolloff = 8
o.wrap = false
o.termguicolors = true

── Search ────────────────────────────
o.ignorecase = true
o.smartcase = true
o.hlsearch = false
o.inccommand = "split"

── System ────────────────────────────
o.clipboard = "unnamedplus"
o.swapfile = false
o.undofile = true
o.updatetime = 300
o.timeoutlen = 300
o.mouse = "a"

── Yank highlight ────────────────────
a.nvim_create_autocmd("TextYankPost", {
  callback = function() vim.highlight.on_yank() end,
  group = a.nvim_create_augroup("YankHighlight", { clear = true }),
  pattern = "*",
})

5 Treesitter

Treesitter gives Neovim real syntax trees for accurate highlighting, indentation, and code folding. We'll install parsers for Lua, Bash, Vimscript, and Vimdoc — covers everything you work with.

💡 Why Treesitter? Built-in vim syntax is regex-based and often wrong. Treesitter parses the actual AST. You can see the difference immediately on any Lua config file.

Create ~/.config/nvim/lua/cggx/lazy/treesitter.lua

-- ~/.config/nvim/lua/cggx/lazy/treesitter.lua
return {
  "nvim-treesitter/nvim-treesitter",
  build = ":TSUpdate",
  config = function()
    require("nvim-treesitter.configs").setup({
      ensure_installed = { "lua", "bash", "vim", "vimdoc" },
      auto_install = true,
      highlight = { enable = true },
      indent = { enable = true },
    })
  end,
}

6 Telescope — fuzzy finder

Telescope is the most essential plugin according to all the blogs. It does file search, text grep, LSP references, diagnostics, and more. It needs ripgrep installed on your system for blazing-fast grep.

Install ripgrep first (if you don't have it):

# On Arch:
sudo pacman -S ripgrep

# Verify:
rg --version

Create ~/.config/nvim/lua/cggx/lazy/telescope.lua

-- ~/.config/nvim/lua/cggx/lazy/telescope.lua
return {
  "nvim-telescope/telescope.nvim",
  tag = "0.1.8",
  dependencies = {
    "nvim-lua/plenary.nvim",
    "nvim-telescope/telescope-fzf-native.nvim",
    build = "make",
  },
  config = function()
    local actions = require("telescope.actions")
    require("telescope").setup({
      defaults = {
        mappings = {
          i = {
            ["<Esc>"] = actions.close,
            ["<CR>"] = actions.select_default,
          },
        },
        file_ignore_patterns = { "node_modules", ".git/", "target/" },
      },
      pickers = {
        find_files = { hidden = true },
        live_grep = { additional_args = { "--hidden" } },
      },
    })
    require("telescope").load_extension("fzf")
  end,
}

9 LSP — code intelligence

Language Server Protocol powers go-to-definition, hover info, autocompletion, diagnostics, rename. We'll set up:

  • lua_ls for Lua (ships with Neovim's Lua API annotations)
  • bashls for shell scripts

We use mason.nvim to install LSP servers and nvim-cmp for autocompletion popups — the same stack used by vineeth, poltora, and jdhao.

Create ~/.config/nvim/lua/cggx/lazy/lsp.lua

-- ~/.config/nvim/lua/cggx/lazy/lsp.lua
return {
  ── Mason: install & manage LSP servers, linters, formatters
  {
    "williamboman/mason.nvim",
    cmd = "Mason",
    config = function()
      require("mason").setup()
    end,
  },
  {
    "williamboman/mason-lspconfig.nvim",
    dependencies = { "williamboman/mason.nvim" },
    config = function()
      require("mason-lspconfig").setup({
        ensure_installed = { "lua_ls", "bashls" },
        automatic_installation = true,
      })
    end,
  },
  {
    "neovim/nvim-lspconfig",
    dependencies = { "williamboman/mason-lspconfig.nvim" },
    config = function()
      local on_attach = function(client, bufnr)
        local opts = { buffer = bufnr, noremap = true, silent = true }
        vim.keymap.set("n", "gd", vim.lsp.buf.definition, opts)
        vim.keymap.set("n", "K", vim.lsp.buf.hover, opts)
        vim.keymap.set("n", "gi", vim.lsp.buf.implementation, opts)
        vim.keymap.set("n", "gr", vim.lsp.buf.references, opts)
        vim.keymap.set("n", "[d", vim.diagnostic.goto_prev, opts)
        vim.keymap.set("n", "]d", vim.diagnostic.goto_next, opts)
        vim.keymap.set("n", "<leader>e", vim.diagnostic.open_float, opts)
      end

      local capabilities = require("cmp_nvim_lsp").default_capabilities()

      local servers = { "lua_ls", "bashls" }
      for _, server in ipairs(servers) do
        require("lspconfig")[server].setup({
          on_attach = on_attach,
          capabilities = capabilities,
        })
      end
    end,
  },
  {
    "hrsh7th/nvim-cmp",
    dependencies = {
      "hrsh7th/cmp-nvim-lsp",
      "hrsh7th/cmp-buffer",
      "hrsh7th/cmp-path",
      "L3MON4D3/LuaSnip",
      "saadparwaiz1/cmp_luasnip",
    },
    config = function()
      local cmp = require("cmp")
      local luasnip = require("luasnip")
      cmp.setup({
        snippet = {
          expand = function(args)
            luasnip.lsp_expand(args.body)
          end,
        },
        mapping = cmp.mapping.preset.insert({
          ["<Tab>"] = cmp.mapping.select_next_item(),
          ["<S-Tab>"] = cmp.mapping.select_prev_item(),
          ["<CR>"] = cmp.mapping.confirm({ select = false }),
          ["<C-Space>"] = cmp.mapping.complete(),
        }),
        sources = cmp.config.sources({
          { name = "nvim_lsp" },
          { name = "luasnip" },
        }, {
          { name = "buffer" },
          { name = "path" },
        }),
      })
    end,
  },
}

10 Status line

Lualine shows you: mode, git branch, filename, filetype, cursor position — all in a clean bar at the bottom. Styled to match the CGGX palette.

Create ~/.config/nvim/lua/cggx/lazy/lualine.lua

-- ~/.config/nvim/lua/cggx/lazy/lualine.lua
return {
  "nvim-lualine/lualine.nvim",
  dependencies = { "nvim-tree/nvim-web-devicons" },
  config = function()
    require("lualine").setup({
      options = {
        theme = "tokyonight",
        component_separators = { left = "", right = "" },
        section_separators = { left = "█", right = "█" },
        globalstatus = true,
      },
      sections = {
        lualine_a = { "mode" },
        lualine_b = { "branch", "diff", "diagnostics" },
        lualine_c = { "filename" },
        lualine_x = { "encoding", "fileformat", "filetype" },
        lualine_y = { "progress" },
        lualine_z = { "location" },
      },
      inactive_sections = {
        lualine_c = { "filename" },
        lualine_x = { "location" },
      },
    })
  end,
}

11 Keymaps & which-key

Your Space leader opens a world of shortcuts. which-key.nvim shows a popup of available keybindings after pressing Space. The keymaps are inspired by vale.rocks and vineeth.

Create ~/.config/nvim/lua/cggx/keymaps.lua

-- ~/.config/nvim/lua/cggx/keymaps.lua
vim.g.mapleader = " "
vim.g.maplocalleader = " "

local map = vim.keymap.set
local opts = { noremap = true, silent = true }

── Better nav ─────────────────────────
map({"n", "v"}, "<Up>", "gk", opts)
map({"n", "v"}, "<Down>", "gj", opts)

── Don't yank on delete ──────────────
map({"n", "v"}, "x", '"_x"', opts)
map({"n", "v"}, "X", '"_X"', opts)

── Telescope ─────────────────────────
map("n", "<leader>ff", "<cmd>Telescope find_files<CR>", opts)
map("n", "<leader>fg", "<cmd>Telescope live_grep<CR>", opts)
map("n", "<leader>fb", "<cmd>Telescope buffers<CR>", opts)
map("n", "<leader>fh", "<cmd>Telescope help_tags<CR>", opts)

── nvim-tree ─────────────────────────
map("n", "<leader>e", "<cmd>NvimTreeToggle<CR>", opts)

── Buffer navigation ─────────────────
map("n", "<Tab>", "<cmd>bnext<CR>", opts)
map("n", "<S-Tab>", "<cmd>bprevious<CR>", opts)
map("n", "<leader>bd", "<cmd>bdelete<CR>", opts)

── Quick escape ──────────────────────
map("i", "jk", "<Esc>", opts)

── Clear search highlight ────────────
map("n", "<Esc>", "<cmd>nohlsearch<CR>", opts)

13 Launch & install

Fire up Neovim — lazy will auto-install all plugins on first launch.

Open Neovim:

nvim

You'll see Lazy's UI install all plugins. After that:

  1. Install LSP servers — run :Mason to verify lua_ls and bashls installed
  2. Install Treesitter parsers — :TSInstall lua bash vim vimdoc
  3. Check LSP — open a .lua file and run :LspInfo. You should see an active client.
  4. Test Telescope — press Space ff to find files
  5. Test nvim-tree — press Space e to toggle the sidebar
  6. Test which-key — press Space and wait a moment

💡 First-launch checklist

── Open neovim, then:
:Lazy           ── should show all plugins installed
:Mason          ── should show luau-lsp + bash-language-server ✓
:TSInstall lua  ── install Lua tree-sitter parser
:checkhealth    ── verify everything is happy

⚡ Quick reference

Keybindings

Space ff   ── Telescope: find files
Space fg   ── Telescope: live grep (search text)
Space fb   ── Telescope: switch buffers
Space fh   ── Telescope: help pages
Space e    ── Toggle nvim-tree
Space bd   ── Close current buffer
Tab / S-Tab ── Next / previous buffer
jk         ── Escape in insert mode
gd         ── Go to definition (LSP)
K          ── Hover info (LSP)
gi         ── Go to implementation (LSP)
gr         ── Find references (LSP)
[d / ]d    ── Previous / next diagnostic

LSP navigation (from poltora.dev)

〞K〞  hover info        〞gd〞  go to definition
〞gi〞 go to implementation  〞gr〞  find references
〞[d〞 prev diagnostic    〞]d〞  next diagnostic
〞<leader>e〞 float diagnostic 〞<leader>rn〞 rename

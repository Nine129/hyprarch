Prototype Notes

• ■ Hovered row — subtle red tint bg, silver text, red left accent (left pane: configs, current pane: btop)
• ■ Selected rows — red tint bg + red left marker (fontconfig, theme.toml)
• ■ Directories — lime with nerd font folder icons
• ■ Images — hot purple #bd00ff
• ■ Archives / executables — cyan
• ■ Config files — orange
• ■ Source code — lime (.rs .py .js .ts .go .c .h .cpp .zig)
• ■ Shell scripts / misc code — lavender #b48cff (.sh .bash .zsh .fish .java .kt .rb .php .hs .pl)
• ■ Logs / binary data — muted (.log .bin .dat .db .sqlite)
• ■ Fonts / documents — silver (.ttf .otf .woff .md .txt .pdf)
• Status bar: HUD mode — bold mode icon + label, powerline separators (open + close), muted labels with colored values
• Scrollbars: colored thumb per pane (muted parent, red current, cyan preview)
• Borders: #2a2a35 between panes, #ff2d55 window border
• Pane headers: icon prefix + item count
• Tabs: red dot on active, muted dot on inactive, red bottom border
• No syntect theme — preview uses neutral highlighting, not Catppuccin
